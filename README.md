# TEAMPLAYER 공식 웹사이트

## 프로젝트 개요
팀플레이어 공식 웹사이트 - https://teamplayer.co.kr

## 기술 스택
- HTML5/CSS3 정적 export
- GitHub Pages

## 주요 기능
- 반응형 웹 디자인
- 다국어 지원 (한국어, 영어, 일본어)
- 다크 모드
- 상담 요청 폼 (개발 중)

## 배포 경계

`.github/workflows/deploy.yml`이 저장소 전체를 GitHub Pages artifact로 배포합니다. 재빌드 가능한 Next.js 원본은 이 저장소에 포함되어 있지 않습니다.

## 디렉토리 구조
```
├── index.html              # 메인 페이지
├── about/                  # 회사 소개
├── products/               # 제품 소개
├── technology/             # 기술 소개
├── partnerships/           # 파트너십
├── support/                # 지원
├── mypage/                 # 마이페이지
├── 404/                    # 404 페이지
├── _next/                  # Next.js 정적 자산
├── teamplayer-logo.png     # 회사 로고
└── favicon.ico             # 파비콘
```
